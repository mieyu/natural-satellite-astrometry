# ADIAS 知识库学习指南

> 整理来源：[ADIAS 飞书知识库](https://my.feishu.cn/wiki/space/7625562537190280387?ccm_open_type=lark_wiki_spaceLink&open_tab_from=wiki_home)  
> 整理时间：2026-09-10  
> 用途：学习 ADIAS 天文图像处理流水线，并作为阅读代码、排查 Python/Fortran 差异时的参照。

## 1. 先建立整体认识

ADIAS 的核心任务，是从原始天文 FITS 图像中检测星象，并结合 GAIA 星表和目标历表，把目标卫星的像素位置换算成赤经、赤纬。

```text
原始 FITS 图像
    ↓
01Pre：背景估计与背景压平
    ↓
02Detect：阈值分割、连通域标记、定中心、SNR 筛选
    ↓
03Match：GAIA 匹配、底片常数求解、目标定位
    ↓
04ComOC：O-C 统计与野值剔除
    ↓
结果文件与统计报告
```

学习时应始终围绕三个问题：

1. 每个阶段接收什么输入、产生什么输出？
2. Python 实现与原 Fortran 实现在哪些地方不同？
3. 差异是否属于正确性问题、精度问题，还是性能与工程实现问题？

## 2. 基础概念

### 2.1 目标信号与背景

天文图像可粗略看作：

```text
图像 = 天体目标信号 + 天空背景 + 仪器噪声
```

背景估计的两个核心量：

- **背景均值 `avervalue`**：去除星点等目标后，纯背景像素的平均亮度。
- **背景标准差 `sigma`**：背景像素围绕均值的波动幅度，代表背景噪声水平。

`cal_b` 使用 Sigma-Clipping：

1. 计算当前样本均值和标准差。
2. 剔除显著偏亮或偏离均值的像素。
3. 对剩余像素重新计算。
4. 反复迭代，得到较稳定的纯背景估计。

需要注意：恒星本身是高亮异常值，但在背景估计中正是应被排除的部分。

### 2.2 读写分离

标准空间滤波通常采用 Out-of-place 方式：

- 输入图像保持不变，只作为读取源。
- 滤波结果写入新的数组。

不要在滑动窗口计算时直接覆盖原图。否则后一个像素的邻域可能包含前一步已经修改过的值，形成数据污染，使结果依赖扫描顺序。

### 2.3 连通性

- **4 连通**：只考虑上、下、左、右。
- **8 连通**：在 4 连通基础上加入四个对角邻居。

天文星象检测通常使用 8 连通。SciPy 中可使用 3×3 全 1 结构元素表达：

```text
1 1 1
1 1 1
1 1 1
```

### 2.4 连通域、并查集、DFS 和 BFS

| 方法 | 核心思想 | 适用场景 | 主要注意点 |
|---|---|---|---|
| 连通域标记 | 为每个独立像素区域分配标签 | 静态二维图像 | 优先使用成熟库实现 |
| 并查集 | Find 查根、Union 合并集合 | 标签等价关系、动态连通 | 配合路径压缩效率很高 |
| DFS | 一条路径走到底再回溯 | 连通块遍历、算法验证 | 大区域递归可能爆栈 |
| BFS | 按距离逐层扩散 | 连通块、无权最短路径 | 需要维护队列 |

`scipy.ndimage.label` 的典型底层逻辑是“两遍扫描 + 并查集”：

1. 第一遍从左上到右下扫描，为前景像素分配临时标签。
2. 遇到不同邻居标签时，记录它们属于同一等价类。
3. 第二遍把临时标签替换为并查集中的根标签。

## 3. 01Pre：图像预处理

### 3.1 阶段定位

01Pre 是流水线第一阶段，负责压平 CCD 图像背景，为后续阈值检测提供更稳定的数据。

- 输入：观测目录中的原始 `*.fit`。
- 输出：同目录下的 `*_n.fit`。
- Header：输出文件保留原始 FITS Header。
- 原图：不得覆盖，因为 03Match 仍需从原图 Header 读取曝光时间等信息。
- 文件列表：需要过滤 `_n.fit`，避免把上次产物再次当成原图处理。

### 3.2 常用处理路径

`superflag = 1` 对应项目中常用的中值滤波路径。已知关键步骤包括：

1. 用 `read_fits` 读图，并转换为 `float64`。
2. 用 `calculate_background(data)` 得到初始背景 `bkgd0` 和噪声 `sigma0`。
3. 使用横向长条中值核，消除一个方向的背景或条纹结构。
4. 使用纵向长条中值核，处理另一个方向。
5. 根据结果恢复或调整背景基准。
6. 可选地使用固定 3×3 均值滤波做进一步平滑。

条状中值滤波与二维中值滤波的区别：

- `1×N` 或 `N×1`：只沿一个方向取邻域，适合有方向性的背景结构。
- `M×N`：二维窗口内统一取中位数，处理更一般的局部背景。

### 3.3 Retinex + 双边滤波路径

此方法用于大尺度背景光照不均匀，例如天光渐变和仪器渐晕。

Retinex 模型：

```text
I = R × L
```

- `I`：观测图像。
- `L`：低频光照或背景分量。
- `R`：星点等高频反射/细节分量。

处理步骤：

1. 把图像归一化至 `[0, 1]`。
2. 计算 `logI = log(1 + I)`，避免对零取对数。
3. 对 `logI` 执行双边滤波，文档中的邻域直径为 `d=15`，得到 `logL`。
4. 计算 `logR = logI - logL`。
5. 指数还原得到反射分量 `R`。
6. 使用 9×9 高斯模糊抑制轻微纹理噪声。
7. 写出 `*_n.fit`，保留 Header。

双边滤波的价值是：在平滑大尺度背景的同时，尽量保留星点边缘和局部结构。

### 3.4 Python 与 Fortran 的已知差异

#### 边界处理

Fortran 的第一次 `1×65` 水平滤波只处理内部区域，两侧各 32 列保留原始像素；Python 库函数的边界扩展和处理方式不同。

#### 分块写入问题

旧 Fortran 逻辑按 1440 像素分块处理或写入。总像素数不能被 1440 整除时，末尾剩余像素可能被替换为背景值，而 Python 会正确写出全部像素。

#### 输出数据类型

| 实现 | FITS 位深 | 数值特点 |
|---|---:|---|
| Fortran | `int16` / `BITPIX=16` | 存在约 ±0.5 ADU 的量化及截断影响 |
| Python | `float32` / `BITPIX=-32` | 保留更多小数精度 |

#### 已观察到的统计规律

测试样本中，Python 预处理结果的全图均值系统性低于 Fortran，差值大约为 `0.3～0.5 ADU`。

- 实验一：`-0.408315 counts/pixel`
- 2024 年 12 月土星数据：`-0.416644 counts/pixel`

该规律在已有样本中保持一致，但不能仅凭单个理论因素判断任意图像的偏差方向，因为边界、数据类型、分块尾部等多个因素会叠加。

## 4. 02Detect：星象检测

### 4.1 阶段定位

02Detect 读取原始或 01Pre 处理后的 CCD 图像，输出 DS9 Region 格式星表 `*.fit.reg`，供 03Match 使用。

```text
背景估计
  ↓
阈值分割
  ↓
连通域标号
  ↓
修正矩定中心
  ↓
信噪比筛选
  ↓
*.fit.reg
```

### 4.2 阈值与连通域

阈值分割把图像转换为前景/背景掩膜。随后对前景像素执行 8 连通标记，把属于同一星象的像素聚合起来。

Fortran 使用自定义三段式流程，并借助 `fort.333`、`fort.334`、`fort.335`、`fort.336` 临时文件去重和合并。Python 可在内存中使用 `list`、`set`、`dict`，或直接采用 SciPy 的 C 实现。

### 4.3 Fortran 等价表问题

Fortran 的 Pass C 大致流程为：

1. 为不同的相邻标签生成等价对。
2. 对等价对去重。
3. 单遍扫描已保存的等价对并进行简化合并。
4. 再次去重。
5. 按等价表替换像素标签。

如果等价对顺序为：

```text
(2,3), (1,2), (3,4)
```

正确结果应是 `{1,2,3,4}` 全部同根。单遍简化不一定能完整传递合并关系；标准并查集则可以保证正确。

Fortran 还使用 ±250 像素的经验搜索范围。这通常能覆盖单个星象或拖尾目标，但可能把大尺度、实际可分离的双星合并。SciPy 会按真实像素连通性处理。

### 4.4 修正矩定中心

对于每个连通域，在去掉外围 10 像素的有效区域内累加：

```text
w_ij      = abox[i,j] ^ pos_method
sumx      = Σ (j+1) × w_ij
sumy      = Σ (i+1) × w_ij
sumi      = Σ w_ij
sumi_real = Σ abox[i,j]
```

定中心结果：

```text
starx = sumx / sumi
stary = sumy / sumi
```

其中 `pos_method` 可在配置中选择 1、2 或 3。坐标使用 `j+1`、`i+1`，是为了与 Fortran 的 1-based 坐标保持一致。

信噪比：

```text
SNR = sumi_real / sqrt(sumi_real + numpix × bkgdsigma²)
```

注意：这里的 `numpix` 只统计内边距有效区域中的像素，并不一定等于连通域最初标记的全部像素数。

### 4.5 已确认的差异根因

对完整流水线采用逐级替换上游输入的控制变量实验后：

- 差异被定位到阶段二检测。
- 将 `minpix` 从 3 调整为 10 后，结果可以对齐。
- 当前持有的 Fortran 源代码并非最新版本。

排查此类问题时，应先保证代码版本和配置参数一致，再讨论算法或浮点误差。

## 5. 03Match：星表匹配与目标定位

### 5.1 阶段目标

03Match 要解决三个问题：

1. 图像里的哪些光点是恒星，哪一个是目标卫星？
2. 当前视场在天球上的准确位置和旋转角是多少？
3. 如何把像素坐标 `(x, y)` 换算成赤经、赤纬？

依赖数据包括：

- 02Detect 输出的检测星位置。
- 原始 FITS Header 中的曝光时间。
- 目标卫星历表。
- GAIA 参考星表。

### 5.2 三层循环

```text
观测日期目录
  └─ 每幅 FITS 图像
       └─ 每个目标卫星
```

每幅图像开始时必须重置 `flag_pre = 0`：

- 该图第一个目标执行完整底片常数搜索。
- 同一幅图中的后续目标复用这组底片常数。

曾经的错误是每天只重置一次，导致全天所有图像复用第一幅图的底片常数。

### 5.3 从 `par_1` 到 `par_4`

#### `par_1`：初始旋转

根据配置文件中的旋转角构造，只是粗略起点。

#### 暴力粗匹配

把每颗检测星依次假设为目标，检查在哪种假设下能与 GAIA 匹配最多参考星，保留最佳假设。

#### `par_2`：第一次参考星求解

以假设目标为像素原点、历表位置为球面中心，使用初次配对的参考星执行 `sol_par`。

#### `par_3`：移动到参考星质心

计算参考星像素位置的质心，把像素原点和球面中心移到视场真实中心附近，再次执行 `sol_par`。这样参考星围绕原点分布更均匀，设计矩阵的数值条件更好。

#### 全图重新匹配

用 `par_3` 把全部检测星投影到天球，再与 GAIA 匹配。底片常数更准确后，通常能得到更多且更可靠的参考星配对。

#### `par_4`：最终底片常数

用扩充后的参考星集合再次执行 `sol_par`，得到最终使用的底片常数。

### 5.4 目标卫星抓取

1. 使用历表赤经、赤纬和最终底片常数，反算目标理论像素位置 `(pre_x, pre_y)`。
2. 在所有检测星中寻找离理论位置最近的目标。
3. 要求距离不超过 3 像素，否则放弃该目标。
4. 再用最终底片常数把实际像素位置换算成观测赤经、赤纬。

### 5.5 五阶段理解框架

```text
检测星 + 历表 + GAIA
       ↓
1. 暴力粗匹配：找目标候选和初始参考星
       ↓
2. 精化中心：移动到参考星质心，提高数值稳定性
       ↓
3. 全图再匹配：扩充并净化参考星集合
       ↓
4. 抓取目标：历表反预报后，在 3 像素内找最近检测星
       ↓
5. 验证：比较初始假设与最终测量结果
```

## 6. 六项仿射模型

像素平面到切平面参考坐标之间使用六项仿射模型：

```text
X = a·x + b·y + c
Y = d·x + e·y + f
```

其中：

- `(x, y)`：图像像素坐标。
- `(X, Y)`：目标平面或切平面坐标。
- `a, b, d, e`：旋转、缩放和错切。
- `c, f`：平移。

对单个输出轴，可写成：

```text
A = [[x1, y1, 1],
     [x2, y2, 1],
     ...]

p = [a, b, c]^T
Z = [z1, z2, ...]^T
```

最小二乘解：

```text
p = (AᵀA)⁻¹AᵀZ
```

实际代码中应优先使用数值更稳定的最小二乘求解函数，而不是显式计算矩阵逆。

使用大量匹配星的原因，是实际观测存在噪声，不可能让所有方程同时完全满足；最小二乘寻找的是整体残差最小的参数。

## 7. 文件和字段参照

### 7.1 `object_*.out`

文档记录了固定宽度字段的格式和字符位置，主要包含：

- 年、月和天内分数日。
- 观测赤经：时、分、秒。
- 赤纬符号以及度、分等字段。
- 后续目标观测和残差信息。

解析此类文件时要严格区分：

- 字符位置是否按 0 索引记录。
- Fortran 固定宽度格式是否包含前导空格。
- RA、Dec 的单位和符号字段。

### 7.2 `04co` 统计字段

主要包括：

1. 日期。
2. 野值剔除前数据量 `raw_count`。
3. 原始 RA/Dec O-C 均值。
4. 原始 RA/Dec O-C 标准差。
5. 野值剔除后数据量 `kept_count`。
6. 剔除后 RA/Dec O-C 均值。
7. 剔除后 RA/Dec O-C 标准差。

O-C 表示 Observed minus Calculated，即观测位置与理论计算位置之差。

## 9. 推荐学习顺序

### 第一阶段：图像与算法基础

1. FITS 文件和 Header。
2. 背景均值、背景标准差、Sigma-Clipping。
3. NumPy 数组精度和读写分离。
4. 中值、均值、高斯和双边滤波。
5. 4/8 连通、DFS、BFS、并查集。

学习目标：能够解释为什么要估计背景、为什么不能原地滤波，以及一颗星如何从像素集合变成一个连通域。

### 第二阶段：掌握 01Pre

1. 跟踪一个 `*.fit` 如何变成 `*_n.fit`。
2. 分清条状中值滤波和二维中值滤波。
3. 理解 Retinex 的乘法模型和对数域相减。
4. 对照边界处理、分块写入和数据类型差异。

学习目标：能解释 Python 与 Fortran 结果为什么会出现约 0.3～0.5 ADU 的系统差异。

### 第三阶段：掌握 02Detect

1. 查看阈值掩膜。
2. 调用 `scipy.ndimage.label` 并检查标签图。
3. 对单个标签手算质心、积分流量和 SNR。
4. 对比 Fortran Pass C 与标准并查集。
5. 验证 `minpix` 对最终目标数量的影响。

学习目标：能从一幅背景扣除图像生成稳定的星象中心列表。

### 第四阶段：掌握 03Match

1. 学习切平面坐标和六项仿射模型。
2. 用已知匹配点练习最小二乘求解。
3. 跟踪 `par_1 → par_2 → par_3 → par_4`。
4. 理解为什么要移动到参考星质心。
5. 跟踪目标从历表位置反算到像素，再回算到赤经、赤纬。

学习目标：能够解释一颗图像中的光点如何被确认成目标卫星。

### 第五阶段：复现实验和排查差异

1. 锁定相同代码版本和配置。
2. 对每个阶段保存中间结果。
3. 采用控制变量法逐级替换上游输入。
4. 先比较数量、尺寸和数据类型，再比较数值。
5. 对差异像素或目标做局部可视化。
