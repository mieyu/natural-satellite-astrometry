# NSPA 界面优化对比记录

记录日期：2026-10-22。适用场景：教师投屏讲解和现场操作演示。

对比基准：[GitHub 主分支 e42d554](https://github.com/mieyu/natural-satellite-astrometry/commit/e42d554d79f733b3f4d438f3f1e07963eb2d1fac)。本文只记录相对该版本已经完成的界面改动。

## 一、改动前后对比

| 项目 | GitHub 基准版本 | 本次改动后 |
| --- | --- | --- |
| 参数名称 | 直接显示 `1superflag`、`3ccd_scale` 等配置键 | 显示中文名称及单位，例如“背景处理方法”“像素尺寸（毫米）”；悬停可查看原参数名 |
| 固定选项 | 通过输入数字或英文填写 | 背景处理方法、平滑开关、设备读取规则、归算模型等改为下拉选择 |
| 常用数值 | 直接输入数值 | 进程数、中心定位权重提供常用选项，也允许输入其他数值 |
| 四阶段说明 | 显示预处理、检测、匹配归算、O-C 统计及英文缩写 | 使用适合投屏的中文标题，并在各组上方增加一句用途说明 |
| 参数解释 | 主要依赖外部配置文档 | 鼠标停留在参数名称或输入框上时，显示用途、单位和必要的取值说明 |
| 参数联动 | 各种处理方法的参数同时可编辑 | 与当前背景处理方法无关的参数置灰；统计模式切换时联动启用残差上限或均值偏差限；切换回来保留原值 |
| 旧版校正参数 | 偏置、暗场、平场兼容参数可编辑 | 标注“未启用”并设为只读，说明当前版本不执行这些校正 |
| 观测日选择 | 自动解析出观测日后，子目录列表变空，不便切换单日 | 明确显示“全部观测日”，列出日期或带层级的相对目录；选中一天时自动定位其 `fits` / `FITS` 文件夹 |
| 输入区布局 | 长预览文字参与上方控件的列宽计算，导致选择框位置变化 | 选择区与预览区独立布局；预览文字按窗口宽度换行，上方选择框不随文字长度移动 |
| 参数错误提示 | 主要提示原配置键及 Python 类型 | 增加中文参数名称；固定选项出现无效值时提示从列表重新选择 |

## 二、参数选择与配置文件的对应关系

中文用于界面显示，生成配置时仍写入原有数字或英文值，保持现有配置格式。

| 界面选项 | 写入配置的内容 |
| --- | --- |
| 中值滤波 | `1superflag=1` |
| 同态滤波 | `1superflag=2` |
| 双边 Retinex | `1superflag=3` |
| 减去背景 | `1bkgdmode=2` |
| 开启 3×3 平滑 | `1enhance_flag=1` |
| 自动选择中值计算方式 | `1median_impl=auto` |
| 兼容旧版星点分组 | `2connectivity=fortran` |
| 六参数线性 | `3modeltype=6` |
| 保留中间文件 | `4del_flag=0` |

载入模板时，将原始值转换为对应中文选项；生成运行配置时，再转换回程序值。焦距、像素尺寸、检测阈值等连续数值仍由输入框填写。选择设备读取规则不会自动改写焦距或像素尺寸。

## 三、观测日选择示例

对于 `inputs/images/U/2020/20201113/fits` 这类数据结构：

1. 选择目标 `U`、观测期 `2020`。
2. “观测日 / 子目录”显示“全部观测日”，预览列出当前识别到的日期。
3. 选择 `20201113` 后，输入路径定位到该日的 `fits` 文件夹。
4. 列表仍保留其他日期，可以切换另一日，也可以返回“全部观测日”。

若观测期下还有月份层级，列表会显示带层级的路径，例如 `202011/20201113`。父目录无法直接解析出观测日时，需要选择具体月份或日期；运行范围以预览信息为准。原有的观测月与历表匹配检查继续保留。

## 五、验证记录与范围

- 5 项针对性测试通过：参数界面 3 项、目录和日期选择 2 项。
- 参数模板回填后，界面显示值可以正确转换回原始配置值；中文选项不会写入数字配置字段。
- 在本机已有天王星目录上，检查了全部日期、单日、不同日期及返回全部日期时的输入路径。只读取目录和文件名，没有执行图像处理。
- 使用长预览文字及窗口缩放检查布局：上方选择框的位置和宽度保持不变，预览区域按可用宽度换行。
- 新增界面测试需要可用的 Tk 环境；天王星多日切换测试在未提供本地图像目录时会跳过。

本次 PR 只包含上述界面、说明文档和对应测试，不修改核心图像处理算法，不上传观测图像、星表、历表或运行结果。检测阶段“背景噪声接近零”的报错不属于本次修复范围。
