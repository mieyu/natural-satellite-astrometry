# NSPA 数据路径与运行结果修复（2026-10-23）

## 本次改动

- 修正 S9 2025 图像目录、GAIA/历表目录和输出目录前导斜杠；将三份旧配置改为项目相对路径并补齐图像目录。
- 输入界面识别 Q_EPH 与 Q_GAIA3；同目标同月优先使用 Q_ 历表，避免 2006 年目标漏选；报告标签同步识别 Q_。
- 独立 report 只选最新时间戳运行批次，不混入旧运行或旧格式结果；没有运行批次时保留旧格式读取兼容性；支持两位数目标序号。
- 预处理、检测、匹配和统计正确返回失败状态；配置拒绝不存在或无原始 FITS 的输入目录；阶段失败或存在失败项时停止后续步骤。仅有提示或主动跳过预处理不视为失败。
- 统计未通过时保留旧文件，但不再把旧的 final_object、日结果和 obsdata 文件列入本次产物。
- Windows 文件清理遇到错误码 5/32/33 时每隔 0.2 秒重试，最多重试 15 次；其他错误和重试耗尽仍抛出异常。
- 配置解析对未知字段、错误类型和无效列表下标报错，给出近似字段提示；校验 O-C 剔除参数，避免无效阈值进入统计。
- O-C 某方向标准差为零时保留该方向的常量数据，同时继续检查另一方向及绝对残差上限。
- 稀疏星场粗匹配先批量筛选候选假设，减少不必要的逐候选查询；密集星场继续走原有路径。
- 结果图支持独立窗口查看、适合窗口、原始尺寸、缩放和拖动平移。
