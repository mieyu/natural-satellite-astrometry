# NSPA 文档导航

从[项目首页](../README.md)了解用途和快速启动；需要操作细节时，按下面的任务查找文档。详细技术资料保存在 `nspa/docs/`，此页作为仓库统一入口。

| 我想做什么 | 阅读 |
| --- | --- |
| 启动桌面程序、选择数据、查看日志或中止运行 | [桌面界面说明](../ui/README.md) |
| 在命令行运行完整流水线或单一阶段 | [核心程序说明](../nspa/README.md) |
| 先看五阶段如何衔接 | [五阶段流程图](../nspa/docs/NSPA五阶段流程图.md) |
| 理解每个阶段的输入、算法和产物 | [五阶段运行详解](../nspa/docs/NSPA五阶段运行流程详解.md) |
| 查找 cfg 参数、数据路径和取值限制 | [配置说明](../nspa/docs/configuration.md) |
| 了解星象检测阈值、连通域和中心定位 | [星象检测详解](../nspa/docs/02Detect星象检测详细说明.md) |
| 学习项目中的天文术语和资料 | [NSPA 知识库学习指南](../nspa/docs/NSPA知识库学习指南.md) |

## 建议阅读顺序

1. 第一次使用：项目首页 → 桌面界面说明 → 配置说明。
2. 理解结果：五阶段流程图 → 五阶段运行详解 → 输出的 O−C 图与 `manifest.json`。
3. 调整检测参数：配置说明 → 星象检测详解。

`assets/` 存放文档使用的示例图。当前的 [O−C 汇总图](assets/oc-summary-s-2023.png)复制自仓库现有的 `outputs/results/S/2023/OC_summary.png`，用于说明报告的输出形式。
