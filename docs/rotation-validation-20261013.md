# 2026-10-13 自动旋转角验证

## 功能

- `3plate_angle=0` 时使用径向距离和方向投票，搜索 0–360°及镜像方向。
- 非零初值的粗匹配失败时回退自动搜索。
- 用独立参考星匹配、SVD 底片拟合、残差及比例检验筛选候选。
- 日志输出求得角度，逐帧 `object_*.out` 写入解算角度。
- 修正高阶模型反算目标时错误地取前六项作为线性参数的问题，并反演完整多项式。

## 模拟验证

`tests/test_rotation_acquisition.py` 覆盖 0°、37.25°、91.4°、178°、271.6°、359.8°，
包含定位噪声、无对应检测源、无对应星表项和镜像方向。
同时验证未知角度、错误初值、6/12/20/30 参数底片的完整匹配，
拒绝无关星表、共线或不足参考星，并验证含实际二阶畸变的目标反算。

本次共运行 29 项回归测试，全部通过。运行方式：

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```

## 限制

九月 2.16 米的数据尚未验证。自动搜索依赖目标历表、观测时间、视场参考星和
近似像元比例，不能保证任何数据都可解算。算法采用有限数量的候选，
强噪声、少参考星、明显畸变或错误仪器参数可能导致失败。
