# 2026-10-12 修复与验证记录

## 修改范围

- 输入界面按观测月选择历表及 GAIA，区分已选与可选数量，阻止缺失或错月的自动选择。
- km100c 从 FRAME、EXPOSURE 解析曝光中点，保留小数秒。
- 每次 O-C 统计生成独立 run 文件，完整流水线报告只读取本次文件，使用历表中的目标代号。
- 界面支持暂停、继续和中止进程树；Windows 启动脚本使用项目虚拟环境。
- 预处理与检测的自动文件并发最多 2 个，并根据图像尺寸及可用内存进一步限制。
- 整型图像背景 sigma 接近零时，从相邻 ADU 档位恢复噪声估计；无法恢复时明确报错。
- 底片解算改为列缩放后的 SVD 最小二乘，拒绝缺乏残差自由度或退化的候选；修正四阶模型重复的 y^4 项。

## 验证边界

- 九月 2.16 米数据尚未验证；参考星几何退化、错误配对或仪器参数错误仍可能导致无解。
- S/2006 试算仍存在检测星不足及 O-C 精度不达标，不能声称该批数据归算成功。
- 内存预算是保守估计，不能排除原生扩展崩溃或其他程序抢占内存；必要时设 workers=1 诊断。
- 暂停、中止功能已实现，本次数值回归未覆盖所有 Windows 进程树操作场景。
- 独立运行 report 仍扫描输出目录；完整流水线才会将报告限定为本次 comoc 文件。
- `inputs/configs/nspa*S*.cfg` 为历史观测模板，需自备 FITS 并核对设备、时间、星表和目标参数。
